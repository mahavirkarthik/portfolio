# Mahavir Karthik — Portfolio

A responsive, static portfolio website built with plain HTML, CSS and JavaScript. It is suitable for GitHub Pages and requires no build step, backend, or framework.

## Preview locally
Open `index.html` in a browser, or run a simple local server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Publish with GitHub Pages
1. Create a GitHub repository, for example `mahavirkarthik.github.io`.
2. Extract these files and place `index.html`, `styles.css`, `script.js`, and `README.md` in the repository root.
3. Push the files to the `main` branch.
4. In GitHub, open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
6. Wait for the Pages deployment to finish. Your site will be available at `https://mahavirkarthik.github.io/` if you used that exact repository name.
